# Clean Python Sample

This repository contains a small Python calculator with simple, readable functions.
It is designed to demonstrate SpotAI-Review's Quality Gate **PASS** state with
the default analysis thresholds.

Run from the SpotAI-Review project root:

```powershell
python spotai_cli.py --repo sample_repos/repo3_clean_python --output-dir reports/repo3_clean_python --fail-on-gate
```
